Notes on implementation:
In modern C++ (C++11 and later), returning a vector by value is actually not expensive due to several optimizations:

Return Value Optimization (RVO) - The compiler constructs the vector directly in the caller's memory
Move semantics - If RVO doesn't apply, the vector is moved (cheap) rather than copied

Recommended approach - just return by value:
cppstd::vector<int> createVector() {
    std::vector<int> result;
    // ... populate result ...
    return result;  // No expensive copy!
}
